# Singularity

Generated by `@wisent-ai/landing-cli@0.2.0` from the 50-page reference context, a described Wisent Components plan, and an approved product brief. Do not hand-edit generated application files.

## Pipeline

1. `landing context` captures all 50 reference observations, the derived guidelines, and the component inventory.
2. `landing components` records every shared component, its description, reason, reference count, and source digests.
3. `landing plan` authors supported copy from the approved product brief inside that format.
4. `landing generate` assembles the page from `wisent-components/src/landing-components.js`.
5. `npm run build:review` creates a non-public review build.
6. After explicit human approval, record the approver, conversation or review reference, and exact statement with `landing approve --site . --by <name> --reference <record> --statement <words>`.
7. `npm run build` is the publication build and refuses missing or stale approval.

Any change to the brief, reference context, component plan, content plan, component runtime, or generated files invalidates approval.
